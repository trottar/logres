## Primary source audit (Blizzard's Forever branch)

The first-party client UI mirror at `https://github.com/Gethe/wow-ui-source/tree/forever` contains these source-verified **different mechanisms**:

1. **Interactive auto-quest popup blocks, inside the Objective Tracker** — `Interface/AddOns/Blizzard_ObjectiveTracker/Blizzard_AutoQuestPopUpTracker.lua` (Git blob `dd6294fc279662e1431e800d801e610d4e24cdf0`) creates `AutoQuestPopUpBlockTemplate` from `GetNumAutoQuestPopUps`/`GetAutoQuestPopUp`. `AutoQuestPopupBlockMixin:OnMouseUp` calls `ShowQuestOffer(questID)` for OFFER and `ShowQuestComplete(questID)` otherwise, then removes the popup. This is **functional native quest interaction**, not an inert cosmetic toast. Silencing/hiding it without preserving these actions is unsafe. Source: https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_ObjectiveTracker/Blizzard_AutoQuestPopUpTracker.lua .
