## P0276 narrow hypothesis and diagnostic

**Hypothesis:** read-only in-client evidence can identify the native trainer's actual decorated regions and retained control hierarchy so a subsequent guarded native-frame reskin can be designed as *one integrated surface* with precise reversible snapshots, rather than guessing geometry or drawing behind the opaque Blizzard core.

1. Retire the P0274/P0275 art implementation (no created overlay, no texture, no mouse layer), retaining a stable inactive `NPCNativeServiceAccent` API for existing placement/restoration diagnostics. It reports `accent=retired` with zeros; these are new-session counters, NOT retroactive evidence that old artwork never rendered.
2. Add separate `Quest/NativeTrainerRegionAudit.lua`, called only on deliberate existing **H — Native Service Frame Audit**. When normalized addon-owned state is interacting/trainer (7), player is out of combat, and ordinary `ClassTrainerFrame` is unprotected and shown, inspect only bounded metadata: frame dimensions/child/region counts, 29 known candidate native controls (including Classic/Forever naming variants) and up to 16 *direct* decorative regions. All native values are checked with `issecretvalue` before type, comparisons, iteration-inspection, string formatting or display. `GetPoint` tokens are NOT read. `GetTexture`/`GetAtlas` are read only on ordinary regions and ordinary results; any unknown/secret result is deferred, not interpreted.
3. Report availability, object type, size, visibility, protection and **method existence only** for possible future texture/alpha/geometry restyling. The audit does NOT authorize mutation or assert that a method is safe; it does not inspect prices, spell costs, eligibility, skill selection, money amounts, scripts, or purchase APIs.
4. Reuse H action and log-export path; **no extra button**, no new hook, no polling, no auto-style, no camera change. Existing whole-frame positioning and restoration remain unchanged. P0274/P0275 historical static contracts are migrated to assert the deliberately retired mode rather than enforce a rejected visual.
