## Narrow hypothesis and instrumentation

The existing P0373 journal has neither the **actual visibility of Logres's own quest root** nor the Show/Hide transition that produced it. That is the specific diagnostic gap for L-034. It also conflates a successful *native handler invocation* with the later *completion outcome* for L-005.

P0375 modifies only Logres-owned observation paths:

1. Hooks **Logres's own `LogresQuestDialogue` root** OnShow and OnHide (additive hooks) and emits `root-onshow` / `root-onhide` events with addon-owned presentation state. Logs the existing `PresentText` intent as `presentation-presented` and lifecycle exit as `presentation-dismissed`. These are observations, **not** a stock-frame scan. The code does not call `QuestFrame:IsShown`, `QuestFrame:SetAlpha`, `Hide`, `HookScript`, or any protected/native presentation state API to prove a mutation.
2. Exposes `rootShown`, declared `presentationShown`, show/hide counters, last presentation reason and turn-in event counters in `QuestDialogue:GetDebugStatus()`. Report Bug gains a `questPresentation` snapshot of these addon-owned fields, so unexpected root visibility can be classified from the next naturally occurring incident. The existing bounded journal remains 384 events and 12 incidents.
3. Registers the client event `QUEST_TURNED_IN` **optionally** using the existing guarded event-registration mechanism. If registration succeeds and a payload arrives, inspect quest ID **only after** `pcall(issecretvalue, questID)` establishes an ordinary value; otherwise record an opaque event without comparing, formatting, or counting a secret-capable payload. This is passive **event evidence**, not a synthetic reward-success inference, and no request/transaction is initiated. `questTurnedInRegistered=false` is a permitted compatibility outcome.
4. Keeps `CompletionControl:Gate`, stock restore before claim, quest 237 preservation, and Blizzard fallbacks unchanged. No timers, polling, forced close, native event hooks, automatic repeat, new saved schema, or debug telemetry upload.
