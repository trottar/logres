## Design and safety

P0321 adds an isolated `NPCGossipStockParking.lua`, rather than expanding trainer parking with a risky blanket family permit. Only after a complete validated live dialogue model is rendered and its every option is covered by an available native-click controller can Logres park the whole **SHOWN** ordinary, nonprotected GossipFrame. The native UI stays shown for Blizzard source functionality; the complete root is moved offscreen through ordinary `ClearAllPoints/SetPoint`, **not** alpha-only hide and **not** mouse-control suppression. Native GetPoint return values are opaque restoration tokens: never branch on, inspect, format, compare or stringify them. SetPoint passes them directly back to the native setter. If any capability is absent, option status is unknown/locked, combat is active, or full coverage cannot be established, fail-open to the visible Blizzard stock window.

Before user-selected gossip choices or quest links can call native APIs, parking restoration is requested; failure blocks the native action instead of risking a stranded hidden service. Goodbye calls guarded native `C_GossipInfo.CloseGossip` after stock restoration; if the capability is unavailable, stock is restored for its own Goodbye. Native `OnHide`, `GOSSIP_CLOSED`, interaction/context change, quest handoff, H toggle and immersion OFF all restore anchor tokens. Combat lockdown defers restoration until `PLAYER_REGEN_ENABLED` and holds the Logres presentation instead of leaving no clickable fallback. No polling, timers, invented family routing or native transactions.
