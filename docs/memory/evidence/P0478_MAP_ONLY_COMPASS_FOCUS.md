The absence of `npc`, `target`, or `mouseover` tokens is not proof that an NPC is absent or on another floor. The return happened *before* candidate accumulation and focus selection; it removed all three candidates in #16482. The same provider feed has X/Y only, no verified Z.

Other native quest POI, manual waypoint, service-order, collision and secure owners remain untouched. `serviceNearUnverifiedHidden` and `providerNearUnverifiedHidden` are retained as backwards-compatible legacy counters, with no new early-return increments.
