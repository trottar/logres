## Narrow design and capability hypothesis

P0278 native scroll/row ornament is a PARTIAL step toward the approved landscape trainer design; it is not the full layout. D-046 requires genuine PREVIEW/live parity rather than separately painted visual lookalikes. P0280 introduces **one independent `NPCTrainerComponents.Render(model)`** and one per-trainer configuration providing style recipes and synthetic fixture placements. Both `NPCTrainerComponents.Preview(owner)` and `NPCTrainerComponents.Enable(trainer)` build the same `{elements}` model shape and call the exact same `Render` painter. Four source-indexed, previously highlighted native control frames are covered: `trainer.filter` (`ClassTrainerFrame.FilterDropdown`), `trainer.selection` (`ClassTrainerFrameSkillStepButton`), `trainer.status` (`ClassTrainerStatusBar`), and `trainer.train` (`ClassTrainerTrainButton`). Each receives Logres-owned parchment wash and gold trim by the shared painter. They remain Blizzard-owned for visibility, state, labels, inputs and transaction actions. No false equivalence: synthetic P labels only demonstrate design and are not a live value adapter or stock label replacement.

The runtime adapter remains read-only toward existing native values and presentation state. The renderer uses guarded `issecretvalue`, `IsProtected`, `IsShown`, width/height, type and combat checks, returns DEFERRED counts when native targets are unsupported, and only adds mouse-inert owned textures to accepted native frames. It does not hide/move/reparent or set alpha on native controls, use secret-capable text/status values, change trainer geometry, call Train or Train All, inspect stock texture state, or poll for recycled rows. On H OFF/close, added ornaments are hidden before the existing root decoration restoration; root alpha snapshot/restore logic is untouched. A missing control is a PARTIAL native styling result, not an unconditional PASS. The synthetic P fixture uses inert frames, shared art recipes and labels; the real Blizzard control fill, typography and interactions remain native and are not falsely simulated as replaced.

Check portrait highlight persistence only incidentally; no forced further trainer visit solely to manufacture evidence. If decorations obscure native labels, glyphs or control feedback, classify VISUAL FAIL and roll back to stock. New ScrollBox rows, landscape reflow, optional design-only elements, native status text/layout, and global HUD/native overlap remain deferred to capability-specific future checkpoints. **P0280 is a deliberately partial component-tranche, not accepted final UI skin.**
