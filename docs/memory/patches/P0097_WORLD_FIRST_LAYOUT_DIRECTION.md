## Decision

Adds D-032 and the world-first layout architecture.

Records:
- optional Active Quest showing only current focus;
- restrained non-mechanical ambient quest wording;
- exact objective detail available on hover/deliberate inspection;
- dedicated transient Context region;
- fixed Primary action role;
- user assignment of supported extra source bars to Secondary/Utility roles;
- Logres-authored action aesthetic rather than a general profile/editor system;
- separate pet/stance/totem/class-control domains;
- world-attached target presentation as intended default;
- detached target frame retained as optional/fallback until replacement is
  capability-proven;
- urgent player debuffs near resources, passive buffs peripheral, target status
  attached to the world target where safe;
- placement by ownership, urgency, and relationship to the world.
