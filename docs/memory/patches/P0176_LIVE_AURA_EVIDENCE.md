Phase H **Status Aura Check** prints one additional live-history line while leaving its existing structural PASS criteria intact.
- **Boundary:** a zero live peak is DEFERRED, not PASS. A positive source peak demonstrates that the source yielded ordinary aura icons during the session; it does NOT prove visual correspondence to every Blizzard debuff, class/raid significance, private aura coverage, or target world attachment. No native frame is hidden. Preview remains distinct; history clears on `/reload` and persists through Immersion OFF/ON and Run All within one session.
- **Validation:** full static suite + candidate hygiene before writes; runtime: Phase H Preview ON/OFF and Check, Phase 0 Run All, naturally acquired debuffs and buffs, Check again after clearing target or aura expiration, confirm history peak/trigger remains and no Lua/secret errors. Negative results stay open until actual evidence.
