## Scope

Implement a **manual, session-only opt-in** normal `MainActionBar` replacement trial, **OFF after reload**. An addon-owned `SecureHandlerStateTemplate` hides its own frame (which temporarily parents Blizzard Main) in secure `normal` mode and securely opens on the special `[petbattle]`, vehicle, override, possess, bonus-bar and form conditions. Stock subtree is actually hidden, not transparent/clickable; no alpha/mouse writes or native Show hooks. Secure mode transition changes each already-key-bound Primary secure button between its normal action and a secure `type=click` delegation to its corresponding genuine Blizzard `ActionButtonN`; no combat-time override binding rewrite. Preserve native dedicated `OverrideActionBar`, and retain the existing Logres normal-paging driver and action visuals. Native Main state/properties remain Blizzard-owned; capture and restore original parent, plus original Logres Primary binding-routing state. Native Main attachment to a different parent during special states is never forcibly overwritten. Immersion OFF and edit-mode entry release gate; exit may re-engage if session armed. Combat-time requested release is deferred until `PLAYER_REGEN_ENABLED`. Explicit ON/OFF/Check controls in Phase D panel.
