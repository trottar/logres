# Camera Architecture

## Product intent

Camera behavior will eventually be integrated into Logres rather than requiring a separate DynamicCam profile.

Known desired contextual categories:
- world;
- combat;
- NPC interaction;
- gathering;
- fishing;
- taxi;
- hearth/teleport;
- instance;
- possibly AFK/rest/travel contexts.

## Evidence requirement

The previously uploaded DynamicCam files are not considered durable evidence for this repository.

Before Phase G implementation, obtain a current export/profile from the user and preserve the relevant settings or a derived record in repository evidence.

Do not reconstruct exact values from conversational summaries.
