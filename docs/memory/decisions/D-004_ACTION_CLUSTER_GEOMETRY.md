# D-004 — Action cluster geometry

Status: ACCEPTED  
Date: 2026-09-30

## Decision

The main action interface uses compact square/rectangular **clusters**, not a traditional long horizontal action bar as its primary aesthetic.

Logical groups:
- Primary Cluster;
- Secondary/Tertiary Clusters;
- Utility Clusters.

## Presentation

Primary remains available. Other clusters fade/reveal by context.

## Constraint

Actual rearrangement/visibility mechanisms must respect secure action and combat-lockdown restrictions established by the API audit.
