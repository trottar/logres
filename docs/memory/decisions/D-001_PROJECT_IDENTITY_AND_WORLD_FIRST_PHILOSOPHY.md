# D-001 — Project identity and world-first philosophy

Status: ACCEPTED  
Date: 2026-09-30

## Decision

The addon is named **Logres** (Project Logres).

Logres is an immersive, world-first interface for World of Warcraft Forever. Its purpose is not merely to minimize the HUD; it deliberately moves attention from numerical/interface abstraction toward the world and contextual perception.

## Consequences

- Feature decisions are judged against the world-first philosophy.
- The addon may intentionally hide information that the API exposes.
- "More information" is not automatically an improvement.
- Warcraft visual identity is preferred over copying another game's visual skin.

## Rejected

- A purely descriptive product name such as `ImmersiveHUD`.
- `Camelot` as the public addon name; the Arthurian connection is retained indirectly through Logres.
