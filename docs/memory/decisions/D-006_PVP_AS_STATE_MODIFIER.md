# D-006 — PvP as a state modifier

Status: ACCEPTED  
Date: 2026-09-30

## Decision

Being PvP flagged modifies Immersion Mode rather than simply disabling it.

The PvP modifier may:
- increase secondary action visibility;
- make relevant target/party information more prominent;
- avoid overly tight cinematic camera behavior;
- shorten reveal/fade delays.

The visual language remains Logres.

## Rationale

PvP raises the cost of missing context, but a conventional maximal HUD is not required merely because the player is flagged.
